# audacia.marketing

Site institucional da Audácia. Esta pasta é o **build publicado**: HTML, CSS,
grafismos e fonte, sem etapa de compilação.

O fonte comentado (onde mora a razão de cada decisão de design) fica fora deste
repositório, e o build que sobe é gerado por `montar-deploy.mjs`, que remove os
comentários internos antes de publicar.

Publicado por GitHub Pages a partir do branch `main`.
